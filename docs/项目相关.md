# 项目相关

## 项目

本项目基于 Monorepo 结构创建，暂未进行独立分包。运行各脚本命令时必须在根目录下操作，并使用 `-F <package-name>` 格式指定目标包。例如，要在下载器项目 [app_core](../packages/app_core) 中安装 Vue，可在根目录执行：

``` shell
pnpm -F app_core add vue
```

## 新建子项目

新建子项目后，需要如下操作：

- 在 [pnpm-workspace.yaml](../pnpm-workspace.yaml) 中添加子项目。然后再次执行`pnpm i`下载子项目依赖。
- 为前端子项目执行检查时，请在对应子包目录内运行 `pnpm check` 或 `pnpm check:prettier`，只检查该子包。根目录的 `pnpm check` 和 `pnpm check:prettier`
  用于全仓检查。新建含 TypeScript/Vue 文件的子项目后，需要在 [eslint.config.js](../eslint.config.js) 的 `_tsProjectCandidates` 中添加其
  `tsconfig.json`，以便 import 路径按项目别名解析。
